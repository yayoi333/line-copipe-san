# 引き継ぎ（handoff）

作業が途中で終わるとき、または次の作業者に渡すときに更新します。
この記録は Git で管理されます。秘密情報や個人情報は書かないでください。

## 確定事項

- AI 作業環境のセットアップを 2026-10-04 に行った。詳細は `docs/ai/setup-report.md`。
- 共通ルールの正本は `AGENTS.md`。`CLAUDE.md` は `@AGENTS.md` で読み込む入口。

## 変更したファイル

- `docs/ai/setup-report.md` の「作成・変更したファイル」を参照。

## 失敗した内容

- なし（セットアップの範囲で）。

## 次に行う一手

1. 所有者がリポジトリを非公開に切り替える（Settings → General → Danger Zone → Change visibility）。切り替えた後、Settings → Pages で公開ページが止まっているかを見る。
2. 非公開になったことを確認してから、作業ブランチを push し、下書きのプルリクエストを作る。main にはまだ入れない。
3. `static.yml` の自動実行を止めるかどうかを、所有者が決める。
4. 新しい Claude Code セッションで `/memory`、`/skills`、`/hooks`、`/permissions` を開き、設定が読み込まれているか確かめる。
