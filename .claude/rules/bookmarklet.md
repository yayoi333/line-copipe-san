# ブックマークレットの編集ルール

## 生成の流れ

- 生成物の扱いと、生成する前の承認は `AGENTS.md` の「変更境界」に従う。
- 生成した後は、3ファイル（`.txt`、`index.html`、`ブックマーク登録用.html`）が同時に更新されたこと、2つのHTMLが一致することを確かめる。terser が使えず簡易圧縮になった場合は、そのことを報告する。
- 生成時に表示される `bookmarklet characters` の値が大きく増えたら報告する。ブラウザごとの URL 長の上限は未確認なので、具体的な上限値を書かない。

## 既存の書き方に合わせる（セットアップ時にコードで確認した内容）

- 全体を即時実行のアロー関数 `(() => { ... })();` で包む。外部ライブラリ、`import`、`require` を使わない。
- `const` を基本にし、必要な場所だけ `let` を使う。`var` は使わない。
- 文字列はダブルクォート、インデントはスペース2つ。
- 既存の短いヘルパー（`q`、`qa`、`nt`、`sleep`、`pad3` など）を使い回す。同じ働きの関数を新しく作らない。

## 互換性と安全性

- パネルの要素ID `lcm-bm-panel`、`localStorage` のキー `lcmBookmarkletPayload` と `lcmBookmarkletTagJson`、クリップボードの接頭辞 `LINE_CM_HELPER:` と `LINE_CM_TAG_JSON:` は、利用者が保存したデータとの互換に関わる。変える必要があるときは利用者に確認する。
- 自動でクリックしているのは、日本語欄の「追加」ボタン、タグの候補、次の画像へ進むボタンだけ。クリックする対象を増やすときは、保存・リクエスト・申請のボタンに当たらないことを確かめる。
- 対象サイトの画面構造（DOM）に依存する変更は、エージェントでは動作を確認できない。実ブラウザでの手動確認が必要だと報告する。
