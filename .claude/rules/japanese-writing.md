# 日本語の文章ルール

README、資料、画面の文言を書くときのルールです。

- 普通の日本語で、具体的に書く。誰が、どの画面で、何をするのかをはっきりさせる。
- 不要な比喩や、大げさな宣伝文句（「最強」「革命的」「誰でも簡単」など）を使わない。
- 一文を短くする。手順は番号付きのリストにする。
- ボタン名や項目名は、コードや実際の画面の表示どおりに「」で囲んで書く（例: 「このページから取得」）。確認できない表示名を推測で書かない。
- 日時・通貨・単位・税込/税別は、依頼や元資料の指定を確認してから書く。指定がなければ書き足さずに確認する。時差の換算や税額の計算を推測でしない。
- LINE の規約や審査基準などの事実は、出典を示す。出典を確認できなければ「未確認」と書く。
- 表記は既存の `README.md` に合わせる（「ブックマークレット」「LINE Creators Market」、数字は半角、句読点は「、」「。」）。
