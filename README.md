# LINE申請コピペさん 統合ブックマークレット

切り出しくん系の画面から申請用テキストを取得し、LINE Creators Market側で貼り付けを補助するブックマークレットです。

## できること

- スタンプ切り出しくん / 絵文字切り出しくんから、英語タイトル、英語説明、日本語タイトル、日本語説明を取得します。
- 絵文字切り出しくんで「番号コピー」が表示されている場合だけ、メイン画像番号4つを取得します。
- LINE Creators Marketの表示情報画面で、英語欄を入力したあと、Japaneseを選んで「追加」ボタンをクリックし、日本語欄へ続けて入力します。
- 絵文字のメイン画像編集画面で、保存済みの3桁番号4つを入力します。
- タグ設定画面で、JSON対応表を貼り付けて自動タグ付けします。
- ブラウザで別サイトへ移動してもデータが消えないよう、取得時に申請データをクリップボードにも保存します。
- 開いているページに合わせて、次に押すボタンだけを濃い緑色で表示します。
- タグJSON欄は「タグ付け」ボタンで開閉できます。タグ設定画面では自動で開きます。
- ChatGPT、Gemini、スキルなどが出したタグ対応表JSONを、回答ページから直接取得して保存できます。
- パネル上部をドラッグすると、好きな場所へ移動できます。

保存ボタン、リクエストボタン、申請ボタンは押しません。入力後はLINE側の画面で内容を確認してください。

## 使い方

1. `LINE申請コピペさん_統合ブックマークレット.txt` の中身をブックマークのURL欄に登録します。
2. スタンプ切り出しくん、または絵文字切り出しくんでブックマークレットを実行し、「このページから取得」を押します。
3. LINE Creators Marketのタイトル・説明文画面で実行し、「英日タイトル・説明を貼り付け」を押します。
4. 絵文字の場合は、メイン画像画面で実行し、「番号を貼り付け」を押します。スタンプの場合、番号は空のままです。
5. タグ設定画面で実行し、JSON対応表を貼り付けて「実行する」を押します。

タグJSONをAI画面から取る場合は、ChatGPTやGeminiなどでJSONが表示されているページ上でブックマークレットを実行し、「タグ付け」→「このページからJSON取得」を押します。JSON欄に入ると同時にクリップボードにも保存されます。LINEのタグ設定画面では「タグ付け」→「クリップボードからJSON復元」を押すと復元できます。

別ドメインへ移動するとブラウザの通常保存領域は分かれます。そのため、このブックマークレットは「このページから取得」を押した時点で、申請データを `LINE_CM_HELPER:` で始まるJSONとしてクリップボードへコピーします。申請画面側で貼り付けボタンを押すと、保存データが見つからない場合はクリップボードから自動復元します。うまく復元されないブラウザでは「クリップボードから復元」を押してください。Safariなどでクリップボード読み取りが止められた場合は、貼り付け用の小さな入力ダイアログが出ます。

## タグJSON形式

```json
{
  "001": ["NO", "断る", "拒否"],
  "002": ["ありがとう", "感謝", "嬉しい"]
}
```

キーは `001`、`01` のどちらでも使えます。値はタグ名の配列、またはカンマ区切り文字列でも動きます。タグ名はLINE側の候補名と完全一致です。

## 生成

元コードは `line-cm-helper.source.js` です。変更後は次を実行するとブックマークレットを再生成できます。

```powershell
node .\build-bookmarklet.mjs
```
